The thinking behind your wardrobe ↗

ATELIER turns daily outfit planning into a practical Java application. Java conditionals validate uploads and compatible outfits. A switch assigns each category to an outfit position. Loops filter the collection, compose random looks, and update saved outfits when a garment is removed. See Closet.java and the README for the assignment walkthrough.
